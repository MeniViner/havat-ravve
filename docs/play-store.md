# Google Play (Trusted Web Activity)

The Android app is a thin Trusted Web Activity (TWA) around `https://havat-ravve.web.app/app`, built with [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap). It adds no server and no paid service. The app stays the website: every deploy updates the Android app too, with no new upload.

Check readiness with `npm run build && npm run play:check` (add `-- --live` to fetch the production site, `-- --strict` to fail on owner items). Statuses: `pass`, `fail` (fix in code), `owner` (needs the farm owner), `pending` (a later step).

## Files

| File | Purpose |
| --- | --- |
| `android/twa-manifest.json` | Bubblewrap config: package name, host, colors, icons, signing key path, fingerprints |
| `scripts/build.mjs` | Writes `dist/.well-known/assetlinks.json` from the fingerprints, only once there is at least one |
| `firebase.json` | Hosting no longer skips dot folders (`.well-known`), and serves `assetlinks.json` as JSON |
| `scripts/play-check.mjs` | The readiness checks |

The signing key (`*.keystore`, `*.jks`) never enters git; `.gitignore` covers it and the check fails if one is tracked.

## Android project and signing

- Package name: `com.menis10tec.havatravve` (approved 2026-11-19; permanent once uploaded). Store and launcher name: "חוות רווה".
- `android/` is generated by Bubblewrap from `android/twa-manifest.json` (template targets API 36, minSdk 24). Regenerate after changing the config, with `@bubblewrap/core` installed outside the repository: `new TwaGenerator().createTwaProject('android', new TwaManifest(json), log)`.
- Upload key: `~/.havat-ravve/android/havat-ravve-upload.keystore` (alias `upload`) on Meni's Mac, outside git. Its password is in the macOS Keychain, item `havat-ravve-android-keystore`. Play App Signing holds the app signing key, so a lost upload key can be reset in Play Console.
- Build and sign a release:
  ```
  cd android && JAVA_HOME=/opt/homebrew/opt/openjdk@17 ANDROID_HOME=/opt/homebrew/share/android-commandlinetools ./gradlew bundleRelease
  jarsigner -keystore ~/.havat-ravve/android/havat-ravve-upload.keystore app/build/outputs/bundle/release/app-release.aab upload
  ```
  Raise `appVersionCode` in `android/twa-manifest.json` (and regenerate) for every upload.
- `fingerprints` lists the upload key and, once Play Console shows it, the Play App Signing key. The build writes both into `/.well-known/assetlinks.json`.

## Account deletion

In the app: My account → "מחיקת החשבון" (`/app/delete-account`, also the public web link for Play). The request is `account_deletions/{uid}` with the server's time; the account is locked and shows a cancel button. After 30 days the Worker cron (`api/src/accounts.ts`) deletes the Firebase Auth user, the profile and the request, and replaces names, phones and notes on the person's tickets, visits, donations and stall accounts. Amounts and dates stay. The Worker's service account needs permission `firebaseauth.users.delete` (custom role `authUserDeleter`).
